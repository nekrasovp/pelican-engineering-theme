# pelican-engineering-theme 0.1.0

Status: first public release.

`0.1.0` is the first documented preview of a generic technical-writing theme
for Pelican. It includes a semantic shell, article/archive/taxonomy surfaces,
default-light and explicit-dark presentation, a stable customization contract,
static notebook output styling, and generic minimal/full examples.

The release supports Python 3.11-3.13 and Pelican 4.11-4.12. It contains no
publisher-specific content, remote fonts, analytics, runtime network service,
notebook reader, or notebook execution.

## Pre-1.0 contract

The documented settings, 18 Jinja blocks, public CSS tokens, color-mode storage
behavior, and `nbconvert-basic.v1` notebook markup are versioned. Before 1.0, a
breaking change requires a minor release and migration notes. This preview does
not claim broad API stability or production-site visual acceptance.

## Verification boundary

Release preparation proves deterministic exact-source wheel/sdist candidates,
clean artifact-only installation, README-derived example builds, the declared
compatibility matrix, exact inventories, docs/screenshot provenance, Chromium,
axe, keyboard/overflow/print behavior, and zero runtime network requests.
The release workflow verifies exact-source artifacts before attaching them to
GitHub and publishing through PyPI Trusted Publishing.

See [the changelog](../../CHANGELOG.md), [compatibility matrix](../compatibility.md),
and [release process](../releasing.md) for details.
